# eFood - Exercício M36

Continuação do projeto eFood do M35.

## Requisitos atendidos

- React
- Styled Components
- React Router
- conteúdo carregado via AJAX com `fetch`
- API oficial da EBAC
- modal de produto
- navegação entre restaurantes
- deploy preparado para Vercel

## API

`https://api-ebac.vercel.app/api/efood/restaurantes`

## Executar

```bash
npm install
npm start
```

## Build

```bash
npm run build
```

## Vercel

O projeto contém `vercel.json` para permitir acesso direto às rotas do React Router.
